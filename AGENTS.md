This is an Expo SDK 58 / React Native interval timer. It is a single-screen app: `index.ts` registers `App.tsx`. There is no Expo Router and no `src/app/` directory. Do not add navigation, tabs, or a backend unless asked.

Prioritize the existing timer behavior, the wheel's visual language, and mobile performance.

## Expo has changed — do not trust your training data

Expo ships breaking changes every SDK release. APIs you remember are likely renamed, moved, or removed. Before writing any code that touches an Expo, EAS, or React Native API:

1. Read the major version of the `expo` package in `package.json`. This project is SDK 58. Do not downgrade it.
2. Fetch the matching versioned docs: `https://docs.expo.dev/versions/v58.0.0/`
3. For anything else, fetch https://docs.expo.dev/llms.txt — an index of all Expo docs with corrections to common LLM misconceptions. Follow its links to the specific page you need; never answer from memory.

## Commands

This project uses npm (`package-lock.json`). Do not switch package managers.

```bash
npx expo install <package>  # ALWAYS use instead of npm/yarn/pnpm/bun add — resolves SDK-compatible versions
npx expo start              # start the dev server
npx tsc --noEmit            # typecheck
npx expo-doctor             # diagnose dependency and config issues
npx expo install --fix      # fix incompatible package versions
npx eas-cli@latest <command> # EAS CLI. Do not run eas build or eas submit unless asked.
```

Run typecheck before declaring a task done. `npx expo lint` is not configured in this project.

## App structure

- `App.tsx` — screen, timer controls, 1:00 / 0:30 cycle pill, set count.
- `timerEngine.ts` — timestamp timer. Elapsed time is the source of truth. Do not drive the clock with Reanimated.
- `components/MinuteWheel.tsx` — wheel presentation and work/rest drag. Reanimated is visual only.
- `components/SetSegments.tsx` — set bars and the set-count wheel.
- `assets/` — icon, adaptive icon, splash image, and favicon.
- Native iOS and Android projects are generated by Continuous Native Generation. Do not create or edit `ios/` or `android/`.

Preserve pause, resume, reset, the work/rest drag, and the set-count behavior unless the task asks to change them.

## Store configuration

App display name is Interval Trainer. The provisional iOS bundle identifier and Android package are `com.intervaltrainer.timer`. That identifier is not confirmed as registered. Do not invent an Apple Team ID, App Store Connect app ID, privacy policy URL, or support URL.

`eas.json` has `preview` (internal) and `production` (store) profiles. Version and build numbers come from `app.json` (`cli.appVersionSource` is `local`). Production builds auto-increment the build number. This repo is not linked to an EAS project yet. Do not build or submit unless asked.

## Rules

- Keep React DOM and React Native Web in the dependency set.
- Prefer Expo modules already in the project over new libraries.
- Expo Go cannot load SDK 58 from the Apple App Store copy of Expo Go. Phone testing needs a matching Expo Go build or a store/development build.
- After adding a library with native code, a new native build is required before that library is available on a device.
